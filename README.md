# SkillHive 🚀

SkillHive is a full-stack web application designed for sharing and exchanging skills, booking sessions, and finding work opportunities.

## 🛠️ Tech Stack
- **Frontend:** React.js, Axios, Socket.io-client, Tailwind CSS
- **Backend:** Node.js, Express.js, Socket.io
- **Database:** MongoDB Atlas
- **Hosting:** Vercel (Frontend), Render (Backend)

## 🌐 Live Demo
- **Frontend:** [https://skillhive-app.vercel.app](https://skillhive-app.vercel.app)
- **Backend API:** [https://skillhive-74fi.onrender.com](https://skillhive-74fi.onrender.com)

## 📜 Features
- Real-time chat & notifications using Socket.io
- User authentication & profile management
- Skill sharing and work opportunity posting
- Matchmaking & booking system
